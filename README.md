# 🚀 Principais categorias de commit
***


## 1️⃣ feat
### Nova funcionalidade.
<
feat: adiciona autenticação com JWT
/>


## 2️⃣ fix
### Correção de bug.
<
fix: corrige erro de validação no formulário
/>


## 3️⃣ docs
### Mudanças apenas na documentação.
<
docs: atualiza README com instruções de instalação
/>


## 4️⃣ style
### Mudanças que não alteram lógica (espaços, indentação, formatação).
<
style: ajusta indentação do controller
/>


## 5️⃣ refactor
### Melhoria interna no código sem mudar comportamento.
<
refactor: reorganiza lógica do service de usuários
/>


## 6️⃣ test
### Adição ou modificação de testes.
<
test: adiciona testes unitários para UserService
/>


## 7️⃣ chore
### Tarefas de manutenção (build, dependências, config).
<
chore: atualiza dependências do projeto
/>


## 8️⃣ perf
### Melhoria de performance.
<
perf: otimiza consulta SQL reduzindo JOINs desnecessários
/>



## 9️⃣ ci
### Mudanças em pipelines (GitHub Actions, GitLab CI etc).
<
ci: adiciona workflow de deploy automático
/>

***
